# BT-EX5 会員サイト

新潟・東京の紹介者制(経営者)コミュニティ BT-EX5 の、会員同士のリファラル(紹介)を増やすための会員限定サイトです。サイトのトップ(`/`)を開くと会員アプリ(`/app/`)に移動し、未ログインの場合はログイン画面を経由します。会員は運営者から届く招待コードで自分のパスワードを決め、以後は「お名前 + パスワード」で入ります(移行期間はコミュニティ共通のパスコードでも入れます)。

## 会員アプリ(`/app/`)

スマホで片手で使えるように、メニューを下の6つのタブにまとめています(早見表・プロフィール・全体分析・名簿の管理にも同じタブが出ます)。数字の丸は未読・未対応の件数です。

| タブ | できること |
| --- | --- |
| **ホーム** | 上から: あいさつと今日のまとめ(やることの件数・次の定例会まで何日)、**今月のあなた**(BT-EX5 内の順位・貢献ポイント・紹介した/された・成約・1on1・ありがとうマイルを1枚に。シェアも)、**紹介先を探す**(聞いた相談を入れるとそのまま早見表の相談アシスタントで検索。`../referral/#ask=…`)、すぐできること(紹介を記録・ありがとう・1on1・ビジター招待・掲示板をアイコン1列)、**あなたのやること**(受付中の出席コード・未対応の紹介・声かけ・パスワード未設定と、担当のやることを1か所に)、次の定例会に1タップで出欠、今週の紹介チャレンジ、運営連絡(あるときだけ)、プロフィールの足りない項目・通知のおすすめ。パソコン(横900px以上)は上を2列、下を「やること・予定」と「チャレンジ・お知らせ」の2列 |
| **探す** | 紹介先早見表(`/referral/`)。相談アシスタント・紹介診断・ジャンル検索。メンバーの詳細から「紹介を記録」「1on1を記録」へそのまま進めます(連絡は詳細の LINE などの連絡先から)(相手が入った状態で開くので、同じことを何度も入力しない) |
| **記録** | **紹介**: 紹介先・紹介した方・連絡先・相談内容を記録すると相手に届き、受けた人は「連絡済み・商談中・見送り・成約 → お礼」で状況を返します。連絡先は紹介した人と受けた人だけが見られます。顔合わせの日時・場所(または Google Meet)も決められ(記録のときでも、あとからでも。紹介した人・受けた人のどちらでも直せて、相手に届く)、「Google カレンダーに追加」「iPhone・Outlook に追加」(.ics。1on1 の入力画面も同じ)と、送る文のコピー(紹介した人は「紹介先のメンバーへ」と「紹介した方へ ― 紹介先の事業内容・ホームページ・SNS・Meet の URL 入り」、受けた人は「紹介された方へ ― 自分のホームページ・SNS 入り」)ができます / **マイル**: ありがとうマイル(紹介で決まった仕事の成約金額を、紹介してくれた人へお礼として記録。1円 = 1マイル) / **1on1**: 予定と記録、自分だけのメモ・次にやること / **ランキング**: チーム内ランキングと貢献ポイント(下の表を参照) |
| **ランキング**(記録 → ランキング) | BT-EX5 の中の**個人の順位**(チームでは分けません)を**貢献ポイント**で見える化。いちばん上の「貢献ポイントのつけ方」を押すと配分が出ます:紹介1件 +1pt・成約1件 +3pt・貢献金額(あなたの紹介から生まれた売上=ありがとうマイル)1,000円ごとに +0.1pt・1on1 +1pt・定例会に出席 +1pt・ビジターの申込1名 +2pt。今月・先月・今年・すべてを切り替え。あなたの順位とポイント、1つ上の順位まで「あと◯pt」、何か月つづけて紹介しているか/BT-EX5 みんなの今月の目標(紹介の件数・貢献金額。管理者が設定、決めていなければ紹介は人数×1件)と達成率/全員のランキング(貢献ポイント・紹介・貢献金額・成約・1on1・出席・ビジターで並べ替え)/あなたの直近6か月の紹介の件数と貢献金額のグラフ。ホームにも順位と「あと◯pt」を出します |
| **数字**(記録 → 数字) | 期間を選んで(← 月 → / 当月 / 前月 / 直近6か月 / 期間指定)自分の数字を見る:出席・出したリファーラル・受けたリファーラル・1on1・ありがとうマイル(受け取った=自分の紹介で相手が成約した分 / 贈った=メンバーの紹介で自分が成約できた分)・招待したビジター(一般 / LINK BT。参加が決まった方を定例会の開催日で数え、同じ方は1人)・入会者数と入会率。選んだ期間は下の**メンバー別の数字**にも効き、全体の合計(リファーラル・マイル・1on1・ビジター・出席)と、メンバーごとのありがとうマイル・リファーラル・1on1・ビジター・出席を表で比べられます。既定はありがとうマイルの順で、順位は ありがとうマイル > リファーラル > 1on1 > ビジター招待 > 出席 の順に比べます(見出しを押すとその項目を先に比べる。項目ごとに1〜4位を金・銀・銅・青で色分け、自分の行は青)。ホームの「今月のあなたの数字」からも開けます |
| **予定** | 上に**立体的な時計**(黒の文字盤×金。日本時間でなめらかに秒針が回り、日付の窓つき)と**カレンダー**(定例会・1on1・紹介の顔合わせ・やることの期限を月ごとに。スマホは色の点、パソコンは予定の名前。日を押すとその日の予定と「＋ 1on1」「＋ やること(その日を期限に)」。`app/calendar.js`)。その下に定例会の一覧と出欠、出席コード(会場で運営が見せる4桁。当日・受付中だけ有効。受付中は時計より上に出す)、ビジター招待(招待URLを作って LINE などで送るだけ。相手は `/visit/` からログインなしで申し込め、申込状況が届く)。管理者は定例会の作成・受付の開始(コード表示)・出欠一覧・手動の出席 |
| **掲示板** | 紹介依頼・イベント・募集・成約・お礼・質問・相談・告知。いいね・コメント・検索。新しい投稿の数をタブに表示 |
| **運営連絡** | 運営からのお知らせ(既読管理・固定・管理者には既読数と未読の人への声かけ文)。未読の数をタブに表示 |

メニュー(タブ)はつかんで好きな場所に動かせます。メニューを画面の端まで持っていく(端に近づける・はみ出させる)と、その辺(上・下・左・右)の離した位置にくっつき(左右は縦並び。左右は高さ、パソコンの上下は横の位置を保存)、それ以外の場所で離すとそこに浮かせて置けます(画面の左右寄りに置くと縦並び、ほかは横並び。画面の大きさが変わっても画面の中に収まる)。端のつまみ(⋮⋮)を押すと、下→右→上→左の順にくっつきます。置いた場所はこの端末に保存され、早見表などほかのページでも同じ場所に出ます(`app/tab-dock.js`)上下の辺の真ん中近くで離すと、ちょうど真ん中にそろいます。パソコンでメニューを左右に置いても本文は真ん中のまま(広い画面では本文の幅も変わらない)です。

パソコンの広い画面(横1100px以上)では本文を最大1120pxまで広げ、ホームは2段組、記録・予定・掲示板・管理のカードは2列で表示します(1件だけのときは横いっぱい)。上の見出しは画面のちょうど真ん中に出ます。

右上の丸(自分の頭文字)は **マイページ**: プロフィール・1on1シートの編集、パスワード、**通知を受け取る**(紹介・掲示板・運営連絡などをスマホに通知。iPhone はホーム画面に追加した BT-EX5 から設定。共有サーバーで動いているときだけ。`app/push.js`・`sw.js`・`gas/webpush.js`)、バグ・要望の送信(運営の返信が見られる)、ホーム画面に追加、ログアウト。管理者には **管理者メニュー**(会員の招待コード発行・まとめて発行、パスワード再設定のコード、ロック解除、すべての端末からログアウト、管理者の指定、共通パスコードの受付停止、バグ・要望への返信)が出ます。

### 手間を減らす工夫

- **入れ直さない**:
  - 相談アシスタント・紹介診断の結果やメンバーの詳細にある「紹介を記録」を押すと、紹介先と相談の内容が入った状態で記録の画面が開きます。
  - 入力の途中で閉じても、紹介・お礼・掲示板は下書きとして残ります(この端末に、ログインした人ごとに保存。送ると消える)。
- **声かけを忘れない**:ホームに次のものを出します。
  - 3日以上「未対応」のままの自分の紹介(押すと、紹介先の詳細が開き、LINE などの連絡先からひと声かけられる)
  - 2日以上返事をしていない自分宛ての紹介
  - 成約したのにお礼を送っていない紹介
  - 今日の 1on1、予定のままになっている過去の 1on1
- **カレンダーに追加**:定例会と 1on1 の予定を、Google カレンダーか iPhone・Outlook(.ics。1時間前に通知)に追加できます。
- **1on1 の予定**:
  - 相手は全員の一覧から選べます(名前・会社・仕事で絞り込み)。日付は「今日・明日・あさって・1週間後」でも選べ、開始時刻(30分ごと)と時間(30分〜2時間)は選ぶだけです。
  - 場所は「現地(対面)」か「Google Meet」を切り替えて選びます。
  - 共有サーバーで Google カレンダーを連携すると、Meet の会議と Google カレンダーの予定を自動で作り、2人に招待を送ります(各自がマイページの「Google カレンダーとの連携」でメールアドレスを登録。ほかのメンバーには表示しない)。設定は `gas/README.md`。
  - 予定の時刻(開始 + 時間)を過ぎると「確認待ち」になり、2人に「◯◯さんとの 1on1 は実施しましたか?」と確認します(ホームの「いまやること」・記録 → 1on1 の上・ベルのお知らせ。共有サーバーではスマホの通知も)。どちらかが「実施した」と答えると「実施」になり、2人とも 1on1 の回数・ランキングに数えられます。「実施しなかった」なら「中止」。答えるまでは数えません
  - 入力画面の日付は「一昨日・昨日・今日・明日・あさって」を1回押すだけで入る。Meet の URL(または場所)を入れたら、「Google カレンダーに追加」で自分のカレンダーに入れ、「相手に送る文をコピー」で日時・場所・Meet の URL 入りの文を LINE などで送れる(予定の一覧からもコピーできる)
- **1on1 の相手探し**:記録 → 1on1 に「次に 1on1 するとよい人」(まだ会っていない人のうち、紹介し合えそうな人)を出します。「1on1 を予定する」で相手が入った 1on1 の予定の入力が開きます。
- **掲示板の検索**:本文・名前・コメントから探せます。
- **運営の手間**:定例会の管理画面で、未回答の人への声かけ文と出欠の一覧(出席予定・欠席・未回答・出席・ビジター)をコピーできます。
- **いつも最新**:ほかのアプリから戻ると、入力中でなければ画面を最新にします(1分以上たっていたとき)。
- **お知らせ(右上のベル)**:自分に関係する出来事(自分あての紹介・紹介の進み具合・ありがとうマイル・掲示板の新しい投稿とコメント・運営連絡・定例会の予定・1on1・ビジターの申込)を新しい順に表示し、押すとその画面へ移ります(過去60日分。記録から毎回組み立てるので、新しく保存するものはありません)。掲示板の新しい投稿は「掲示板」タブ、未読の運営連絡は「運営連絡」タブの数字にも出ます。共有サーバーでは、同じ出来事をスマホの通知でも受け取れます(マイページ →「通知を受け取る」)。
  - 紹介が届いた/自分の紹介の状況が変わった/お礼が届いた
  - 自分の投稿(または自分もコメントした投稿)にコメントがついた
  - 相手が 1on1 を記録した/招待したビジターが申し込んだ
  - 運営連絡/新しい定例会
- **QR コード**(`app/vendor/qrcode.js`。MIT ライセンス。サイト内に置いているので電波が弱くても出る):
  - 定例会の受付を開くと、出席コードと一緒に QR コードが出ます。スマホのカメラで読み取るとそのまま出席になります(ログインしていなくても、ログイン後に出席まで進みます)。
  - ビジター招待で、目の前の相手に申込ページの QR を見せられます。
  - マイページから自分のプロフィールの QR を出せます。
- **LINE でも知らせる**:紹介を記録したとき・ありがとうを送ったときに、相手へ送る文(紹介した方・相談内容・連絡先・サイトのリンク入り)を用意し、「LINE などで送る」で共有できます。
- **ロゴ**:見出し・ログイン画面などのロゴは、オープニングムービーと同じ 3D の金のロゴを書き出した画像(`assets/bt-ex5-mark-3d.png`。作り方は `opening/src/logo3d.html`)。ブラウザのタブの小さなアイコンは SVG(`assets/bt-ex5-mark.svg`)、アプリのアイコン(`assets/icon-*.png`)も 3D のロゴ
- **スマホの通知の種類**:マイページ →「通知を受け取る」で、紹介・1on1・掲示板・@で名前が出たとき・運営連絡と定例会・やること・ビジターを、種類ごとにオン・オフ(切った種類もベル🔔には出る。サーバーの `PUSH_GROUPS`)
- **出した紹介の進み具合**:記録 → 紹介の上に、状況ごとの割合の帯と成約率(結果が出た紹介のうち成約の割合)
- **オフラインの知らせ**:電波がないときは上に「オフラインです」と出る(戻ると消える)
- **掲示板の「@名前」**:投稿・コメントで「@」「＠」と入れるとメンバーの候補が出て、選ぶと「@山本捷真」の形で入ります。名前を出された人には、ベルとスマホに「掲示板であなたの名前を出しました」(フルネーム・空白なし・名字だけ(同じ名字がいないとき)で読み取る。サーバーの `mentions`)
- **BT-EX5 全体の今月(ホーム)**:今月、メンバー全体で出た紹介・成約・1on1・掲示板の投稿の数
- **引っぱって更新**:スマホで画面のいちばん上から下へ引っぱって「はなすと更新」と出たらはなすと、いまの画面を最新にします
- **プレゼンの練習・タイマー**(マイページ・定例会の詳細から):30秒プレゼンの原稿(本人だけが見る。サーバーに保存)・文字数と読む時間の目安(1秒に約8.5字。30秒は250字、1分は500字)・プロフィールからひな形・読み上げ。タイマーは 30秒・1分・3分・5分・10分・25分(ポモドーロ)から選べ、一時停止・つづけるができます。残りわずか(1分までは残り10秒、それより長いときは残り1分)で小さな音、0秒で鐘の音(Web Audio で作る。音のオン・オフと長さはこの端末に保存)、色とふるえでも知らせ、動いているあいだは画面を消しません(対応する端末)(`app/pitch.js`)
- **今月の目標**:紹介・成約・1on1・ビジター招待の数を決めると、ホームの「今月のあなた」に進み具合のバー(サーバーに保存。ほかの人には見えない)。ホームの入力されていないプロフィールの案内には、入力の割合(%)
- **アプリ内を探す**:上の 🔍(パソコンは「/」か Ctrl+K・⌘K)で、メンバー(名前・会社・事業・求める紹介・こんな話が出たら)・掲示板・運営連絡・定例会をまとめて探せます。見つかった言葉に印、Enter でいちばん上の結果へ(`app/search.js`)
- **今日・明日の予定(ホーム)**:1on1・紹介の顔合わせ・やること(時刻・期限)を、今日と明日に分けて時刻順に。今日の Meet はその場で参加(定例会は下の「次の定例会」)
- **最近の相手**:紹介・1on1・ありがとうなどで相手を選ぶとき、最近えらんだ人(この端末で新しい順に8人まで)を上に出し、1タップで選べます
- **やることの直前のお知らせ**:時刻つきのやることは、1on1 と同じく時刻の約3時間前から、ベルとスマホの通知でお知らせします(サーバーの1時間ごとの見回りで送るので、届く時刻には幅があります)
- **自分だけのやること**:カレンダーやホームから自分で入れる「やること」は、はじめから「自分だけが見られる」(ほかのメンバー・運営には見えず、運営ダッシュボードにも出ず、管理者も直せない・消せない)。定例会のやること(議事録から)はこれまでどおり共有。時刻(任意)を入れられ、保存したあとに「Google カレンダーに入れる」「iPhone・Outlook(.ics)」で自分のカレンダーへ(時刻なしは期限の日の終日)。運営のカレンダーは通さないので、中身は運営に渡りません。やることの一覧の「カレンダーに追加」からも入れられます
- **紹介診断は3問**:「困りごと → 方法 → 相手はどんな方か」の3つだけ。業種・エリア・会い方の質問はなくし、点数では「わからない・どこでも」として扱います(`referral/referral.js` の `STEPS`・`SKIPPED`)。相談アシスタントは、相談の文章から業種・エリアが読み取れればこれまでどおり使います
- **人手不足の相談**:「人手が足りない」「スタッフが足りない」「人が採れない」「手が回らない」などは、採用・人手不足に加えて「システム開発で人手を補う」(業務効率化・AI・公式LINE)としても読み取り、相談アシスタントのチームに両方を出します。紹介診断でも「人を採用したい・人手が足りない」の2番目の方法に「システム開発で人手を補う」を置いています。「足りなくて」「足りなかった」も読めるよう、言葉は「足りな」で探します
- **掲示板の投稿を LINE へ**:各投稿の「LINE 用にコピー」で、本文とアプリのリンク(`#board?post=…`。開くとその投稿まで動いて光る)を LINE に貼れる形でコピーします
- **定例会の直前**:開始1時間前から終わるまで、出席予定の人には「開始まで あと◯分」と大きな「いま Google Meet に参加する」ボタンを出します
- **カレンダー・時計・上へ**:予定のカレンダーはスマホで左右にはらうと月が変わります。時計はスマホで画面幅の約4分の3(最大300px)、パソコンで290px。長い画面では右下に「↑」(いちばん上へ)
- **運営連絡を LINE へ**:運営連絡を開くと「LINE に貼る文をコピー」「LINE などで送る」が出ます。件名・本文・アプリのリンクが、LINE のトークにそのまま貼れる形で入ります
- **「null」の文字の掃除**:入っていない値がつながった「null」「nullnull」などの文字は、どの画面にも出しません。共有サーバーに保存されていたものも、一度だけ自動で消します(`server-community.js` の nullish-1。ログイン・通知の登録・鍵は触らない)
- **システム改善のお知らせ**:これまでの改善点を、改善した日ごとに運営連絡へ入れています(`referral/data.js` の `REF_SEED_ANNOUNCEMENTS`。どの端末・共有サーバーにも一度だけ入り、消しても戻らない。投稿日は改善した日で、未来の日時にはしない)。新しく改善したら、ここに1日分を足します。すでに入っているお知らせの中身を書き直したときは、その項目の `rev` を1つ上げると、共有サーバーの投稿も件名・本文が書きかわります(既読はそのまま。新しい投稿は増えない。消した投稿は戻らない)
- **ホーム画面のアイコンに未読の数**:ホーム画面に追加したアイコンに、未読の運営連絡と未対応の紹介の数を出します(対応している端末のみ)。
- **出席率**:予定の画面に、最近の定例会の自分の出席率を表示します。
- アプリの中で画面を移ると、開いていた入力シートは閉じます(書きかけは下書きに残ります)。
- **文字を大きくする**:マイページで切り替えると、この端末のすべての画面(早見表・プロフィールなども)の文字が大きくなります。
- **今月の数字をシェア**:ホームの「今月のあなたの数字」を、チームの LINE などに送れる文にします。

### 運営の手間を減らす(管理者)

- **運営ダッシュボード**(マイページ → 管理者メニュー):
  - 月ごとに、紹介・成約・ありがとうマイル・1on1・ビジター申込・掲示板の投稿を、前の月との差つきで表示します。
  - その月の定例会ごとの出欠・出席率・ビジターを表示します。
  - **声かけが必要なメンバー**:まだログインしていない・30日以上ログインしていない・出席率50%未満・その月の動きがない人。連絡ボタンと、全体への声かけ文のコピーがあります。
  - メンバーごとの数字の表を表示します。
  - **CSV の書き出し**:紹介・ありがとうマイル・出欠・ビジター・1on1 を、Excel で開ける CSV にします。紹介した方の連絡先は含めません。
- **ビジター招待**(`#invite`。ホームの「ビジターを招待」・定例会のカード・マイページから):
  - **招待の前に確認すること**:系列チームのクリエアドバンスへの事前共有・確認、招待の手順(外部の方 / LINK メンバーの方)、やってはいけないこと。一度閉じると次からは閉じた状態で表示します。
  - **招待を作成**:対象定例会(申込締切前のもの)、お招きする方(一般の方 / LINK BT 会員の方)、相手の氏名・会社名・メールアドレス・メッセージ(任意)→「招待URL を発行」。文の共有(LINE など)・コピー・URL だけコピー・QR コードを表示します。「URL 発行 + メールで送る」は、メールアプリに招待文が入った状態で開きます。
  - **そのまま使える文(ボタンでコピー)**:①クリエアドバンスへ事前共有(外部の方の許可のお願い / LINK メンバーの報告)②相手に送る(LINE 向けの短い文 / メール向けの丁寧な文 / LINK メンバーへの案内)③そのあと(前日のリマインド / 参加のお礼)。相手の名前・定例会の日時・招待URL が自動で入ります。「見る」で中身を確かめられます。
  - **招待履歴**:日付・相手・種別(一般 / LINK会員)・会社・対象定例会・状況(招待中・参加申込・参加確定・参加済み・入会・キャンセル)。詳細から URL・リマインド文のコピー、キャンセル。
  - 相手の申込ページ(`/visit/`)には、入れておいた氏名・会社名とメッセージが最初から入ります。LINK BT 会員として招待した方には、所属チーム・アップ・アドバンスも聞きます。
- **定例会の詳細**(予定 → 定例会 →「詳細・出欠の一覧を見る」):開催日時・参加費・参加予定・申込締切、開催場所(オンラインは申し込んだ人にだけ Google Meet の参加リンク)、当日の流れ、ご案内、出欠の登録(締切を過ぎると変えられない。未回答なら赤字でお願い)、懇親会の出欠、メンバーの出欠一覧(出席・欠席・未回答に分けて、チームと事業も)、申込ビジター(種別・紹介者・状況。管理者はテキストで書き出し)。BT-EX5 の定例会(10/7・10/17・11/4・11/14)を最初から入れています(`referral/data.js` の `REF_SEED_EVENTS`。参加リンクと各会員の出欠は、誰でも読めるファイルに置かないため入れていません)。
- **定例会を作ると Google Meet も作成**:管理者が「オンライン(Google Meet)」で定例会を作ると、共有サーバーで Google カレンダーを連携していれば、運営のカレンダーに予定と Google Meet が自動でできます(お試し版では「Meet を作る」で作った URL を貼り付け)。前回の定例会の内容(当日の流れ・ご案内・参加費・締切)をひな形として最初から入れます。
- **出欠は Google Meet の参加時間で自動判定**:オンラインの定例会は出席コードを使わず、Meet に **100分以上参加 → 出席、60分以上100分未満 → 遅刻早退** にします(設定は `gas/README.md`)。管理者は管理画面で、出席・遅刻早退・—を1タップで直せます。会場で開く回だけ、これまでどおり出席コード・QR コードが使えます。
- **定例会の繰り返し作成**:「毎月(同じ週の同じ曜日。例:第2月曜)」「毎週」「隔週」で、最大12回分をまとめて作れます。作る日を先に確認できます。
- **運営連絡の未読者**:まだ見ていない人の名前を表示し、その人たちへの声かけ文をコピーできます。

### お試し版で入力したプロフィールの移し方

お試し版では、自分の情報の編集はその端末のブラウザの中にだけ保存されます(ほかの端末からは読めないため、運営や開発側で集めることはできません)。

- **いま**:本人がプロフィール画面の「入力した内容を運営に送る」を押すと、内容と取り込み用のコード(`BTEX5-PROFILE:…`)が入った文ができるので、LINE などで運営に送ります。運営は管理者メニュー → ダッシュボードの「プロフィールを取り込む」に貼り付けます。届いた文を開発担当に渡せば、初期名簿(`referral/data.js`)に入れて全員の端末に反映できます。
- **共有サーバーに切り替えたあと**:その端末でログインすると、お試し版で入力した内容が残っていれば「共有サーバーに送りますか?」と一度だけ聞き、送れます(`auth/profile-transfer.js`)。

### 本番に切り替える手順

1. `gas/README.md` の手順で共有サーバー(Google Apps Script)を設置し、`auth/api.js` の `API_BASE_URL` を設定する
2. 管理者用パスコードでログイン → マイページ → 管理者メニュー →「まだの○名に招待コードをまとめて発行」→ 招待文を各自に LINE などで送る(コードは14日間有効。発行し直すと前のコードは無効)
3. 運営メンバーを「管理者にする」(以後は自分のパスワードで管理者として入れる)
4. 全員が「利用中」になったら「会員用の共通パスコードでのログインを受け付ける」を外す(管理者用パスコードは非常用として残る)

## 主な機能(紹介先早見表など)

- **紹介先早見表**(`/referral/`)— 会員ごとに「事業内容/求める紹介/こんな話が出たら(トリガーワード)/活動範囲(対面・オンライン)」を表形式で一覧化。キーワード検索・話題・業種・対応エリアで絞り込めます。業種は「IT・Web・クリエイティブ」を AI研修・AI活用/システム開発/Web制作/SNS運用・集客/動画編集・映像制作/企業PR動画制作/作詞作曲・音楽制作/声・司会・キャスティング/デザイン・ブランディング/EC・ネットショップ に分けており、本業でなくてもその仕事を扱う人(話題で判定)も出ます(`referral/data.js` の `REF_CATEGORY_GROUPS`・`REF_CATEGORY_TOPICS`)。各カードには、その人ができること(ジャンル)をタグで複数表示し、タグを押すとそのジャンルで探せます。ジャンルは9つのまとまり・48種類(`referral/data.js` の `TOPICS`。本人のプロフィール・名簿の管理でいくつでも選べます)。「ジャンルで探す」では、その話題だけを選んだ紹介診断と同じ計算の一致度(専門の人ほど高く、代表・役職・役割の基礎ポイントを含む)の高い順に並び、カードに一致度を表示します
- **相談アシスタント** — 早見表の一番上の欄に、会話で聞いた相談を文章で入れるか「話して入力」(音声入力。対応ブラウザのみ)で話すと、必要なジャンル・相手の業種・相手のタイプ・エリアを読み取り、紹介診断と同じ計算で候補を出します。困りごとが2つ以上あるときは「この組み合わせで、まとめて解決できます」としてチーム(困りごとごとに1人)を提案し、「チームの紹介文をコピー」で送れます。対応できるメンバーがいないジャンルは、全体分析の「必要な業種」へ案内します。外部の AI は使わず、端末の中で読み取ります(`referral/consult.js`、言葉の辞書は `referral/data.js` の `CONSULT_PHRASES` など)
- **紹介診断(マッチ率)** — 相手の「困りごと」(採用・人材育成・集客・単価アップ・SNS発信・業務効率化・お金・場所・制作・イベント・美容健康・暮らしの12分類)を選び、次にその課題を解決する具体的な方法(例: 集客なら SEO・MEO・AIO/PR動画/SNS運用…、分からなければ「おまかせ」)を選び、相手のタイプ・業種・エリア・会い方に答えると(6問。課題の分け方は `referral/data.js` の `REF_NEEDS`)、会員ごとの一致度(0〜100%)を計算し、上位5名を理由つきで表示。一覧を一致度順に並べ替えることもできます
- **定例会の議事録・決定事項** — 管理者は定例会の詳細(当日・終わったあと)で「議事録を書く」から、決まったこと・次回までにやることを残せます。「運営連絡で全員に届ける」で運営連絡として配られ(スマホにも通知)、直したときは同じ運営連絡がもう一度未読になります。メンバーは定例会の詳細(これまでの定例会に「議事録」の印)でいつでも読めます
- **やること(担当・期限つき)** — ホームの「あなたのやること」にチェックで完了。自分のやることを足せるほか、管理者は定例会の詳細の「やること」から、議事録の「次回までにやること」を担当(個別・全員)と期限つきで配れます(定例会の詳細で、だれが済ませたかが分かる)。管理者のダッシュボードの「やることの進み具合」で、終わっていないやること(期限切れは赤)・まだの人・期限切れのある人が分かり、「声かけ文」でまだの人への文をコピーできます。割り当てられたとき・期限の前日の朝に、ベルとスマホの通知で知らせます(`app/tasks.js`)
- **掲示板の投稿・コメントを直す** — 自分の投稿は「編集」で種類と本文を、自分のコメントも「編集」で直せます(「編集済み」と表示)
- **今週の紹介チャレンジ** — ホームに、最近(60日)紹介を受けていないメンバーを週ごとに1人出します(求める紹介・こんな話が出たら・紹介特典つき)。「紹介を記録する」で相手が入った記録の画面が開きます。紹介が回っていない人に光を当て、全員に紹介が届くようにするため
- **紹介の絞り込み** — 記録 → 紹介 で、状況(未対応・連絡済み・商談中・成約・見送り。件数つき)とお名前・会社・相談の内容で絞り込めます(紹介が4件以上のとき)
- **予定の重なりの確認** — 1on1 や紹介の顔合わせを保存するとき、同じ時間に自分の 1on1・顔合わせ・出席予定の定例会があれば「同じ時間に次の予定があります」と確かめます
- **自分の記録を書き出す** — マイページ →「自分の記録を書き出す(Excel)」で、出した紹介・受けた紹介・ありがとうマイル・1on1 を CSV で保存できます(Excel・Google スプレッドシートで開ける)
- **声かけの自動化(ホームの「いまやること」・ベル・スマホの通知)** — 1on1 と紹介の顔合わせは始まる3時間前に「◯時から◯◯さんと 1on1 です」「◯時から紹介の顔合わせです」(Meet の URL 入り)、当日はホームに「今日は◯◯との顔合わせです」(押すと Meet に参加)。定例会の2日前になっても出欠がまだの人に「出欠がまだです」、自分が招いたビジターが参加したら(14日以内・入会か見送りが決まるまで)「入会のご案内を」、時刻を過ぎた 1on1 に「実施しましたか?」を出します
- **退会・名簿から外したとき** — 名簿の管理で削除すると、その人のアカウント・ログイン中の端末・スマホ通知の登録も消え、ログインできなくなります(紹介・マイル・1on1 の記録は残り、名前は「退会したメンバー」と出ます)
- **共有サーバーの毎日のバックアップ** — 7日分を自動で保存し、`restoreLatestBackup` で戻せます(`gas/README.md`)
- **検索の公平さと記録** — 合う人が多いときは、上位2名は一致度の順のまま、3位から下を「3位との差が5点以内の人」から日替わりで選び(ジャンルで探すときも同じ%の人は日替わりの順)、毎回同じ人ばかりが出ないようにしています(`referral/scoring.js`)。紹介診断・相談アシスタント・ジャンルで探す の結果に出た人を日ごとに記録し、管理者メニューのダッシュボード「検索での表示」でメンバーごとの回数・1位の回数・ジャンル数、検索に出ていないメンバー(プロフィール入力のお願い文をコピー)、相談アシスタントが読み取れなかった相談(言葉の辞書を足す材料)を見られます。本人は 記録 →「数字」で、期間内に検索結果に出た回数を見られます。相談の言葉の辞書には、美容・体の不調・癒やし・贈り物・販路・住まい・お金の将来・子ども・介護・海外・地域・話し方・税金と契約などの言い方も入れています
  - 話題は6グループ・28項目(仕事・集客/お金・法律/人・組織・成長/住まい・地域/健康・暮らし/食・イベント)。ほかの人と重ならない具体的な話題(例:ケータリング・パーティー料理、会場・レンタルスペース、ネットショップ・EC)を持つ人が、その話題で確実に上位に来ます
  - 配点: 話題50(選んだ話題をどれだけ扱えるか42+本業に近いか8)+ 業種15 + 相手のタイプ10 + 会い方・エリア25(キーワード一致で+15)。話題もキーワードも一致しない人は30%で頭打ち。未入力の項目は中立の点数(活動範囲は25点中15点)
  - 同点のときは、キーワードが多く一致した人、扱う話題が少ない専門の人の順(名簿の並び順では決めない)
  - キーワードは、本人の説明文にその言葉があれば+15、話題の言いかえ(`TOPIC_KEYWORDS`。例:「婚活」→結婚・子育て)に当たれば+8(選んだ話題の言いかえは二重に数えない)
  - 計算は `referral/scoring.js`(画面に依存しないので、回答の全組み合わせでの出やすさを確かめられます)
- **紹介文をコピー** — 診断した話題を織り込んだ紹介文を自動作成してコピー。本人が「自己紹介文」を登録していれば、それを原文のまま入れます(自己紹介文はキーワード検索の対象にもなります)
- **キーワード検索の言いかえ** — 本人の説明にその言葉がなくても、言いかえで当たるジャンルを持つ人が出ます(例:「人が辞める」→ 離職防止)。検索欄の下に「関連するジャンル」を出し、押すとそのジャンルで探せます
- **打診文・まとめて紹介** — 詳細と診断結果の「打診文をコピー」で、紹介してよいかをメンバーに先に聞く文(診断の困りごと・方法入り)を作れます。診断結果の「上位3名をまとめてコピー」で、困っている相手に候補を一度に送れます。`/referral/#member=ID` を開くとその人の詳細が出ます(ログイン前に開いてもログイン後に表示。プロフィールの QR コードなどで使用)。診断の結果は、タブを閉じるまで再読み込みしても残ります
- **マイページ** — 会員アプリ(`/app/#me`)に移りました(`/portal/` を開くと移動します)。`/referral/#diag` で紹介診断を開いた状態で表示します
- **1on1シート** — 自分の情報に「強み・選ばれる理由/紹介するときのひとこと/紹介の注意点・NG/いまの目標/人柄」を書け、メンバーの詳細に表示されます
- **自分の情報の編集**(`/profile/`)— 項目へのジャンプ、まだの項目を押すとその入力欄へ移動、保存ボタンは画面の下に固定、未保存の変更があると表示しページを離れるときに確認、「一覧での見え方を見る」で自分の詳細を表示
- **名簿の管理の便利機能** — 各メンバーの記入率(%)・最終更新(本人/管理者)・ジャンルのタグを表示。並び順(記入が少ない順・最近更新した順・名前順)、ジャンルや事業内容での検索、「早見表で見る」、Excel で開ける CSV の書き出し。編集中は枠の外を触っても閉じず、未保存の変更があれば閉じる前に確認し、保存ボタンは画面の下に固定
- **ホーム画面に追加** — `manifest.webmanifest` とアイコン(`assets/icon-*.png`)で、スマホのホーム画面からアプリのように開けます(開くと会員アプリのホーム。アイコンの長押しで「紹介先を探す」「紹介を記録」「予定・出席コード」「掲示板」へ直接)。マイページに追加の方法を表示
- **知り合いを誘う文** — 全体分析の「BT-EX5 に必要な業種」の各カードから、その業種の知り合いを誘う文をコピーできます。名前を押すと早見表でその人の詳細が開きます
- **自分だけのメモ** — 詳細画面でメンバーごとにメモを残せます(交流会で話したこと・名刺交換したか など)。この端末に、ログインした人ごとに保存され、本人や他の会員には見えません。カードに「メモあり」が出て、メモの言葉でもキーワード検索できます。パソコンでは「/」でキーワード検索へ移動
- **電波の弱い会場でも開ける** — `sw.js`(サービスワーカー)が、一度開いたページと JS・CSS・画像を保存し、つながらないときは保存したものを出します(ページはネット優先、動画とほかのサイトは対象外)
- **お気に入り** — カードの☆でお気に入りに登録し、「★ お気に入り」で登録した人だけを表示できます(この端末に、ログインした人ごとに保存)
- **あなたと紹介し合えそうな人** — 同じお客様を持ち、別のサービスを出している人を早見表の上部(と各メンバーの詳細画面)に3名まで表示。「求める紹介」とお客様・事業の言葉の重なり、「求める紹介」に当てはまる話題、紹介してほしい業種の重なりで計算し、扱う話題がほとんど同じ人(競合しやすい人)は下げます(`referral/partners.js`)
- **紹介特典** — 「BT-EX5のメンバーから紹介されたお客様への特典」(例:初回相談無料)を各自が登録でき、カード・詳細・紹介文に入ります。「紹介特典あり」で絞り込めます(登録している人がいるときだけ表示)
- **並び順** — 検索・診断の前の一覧は、1番目が利用者本人。そのあとは役職・役割の基礎ポイントの高い順(桜羽 李果 +10、大場 雅俊 +9、小林 末季こばねぇ +8、あまみや 七音 +7、三村 隆 +6、山本 捷真 +5)。この6名は名前の下に代表(金)・役職(赤)・役割(紺)のマークが出ます、ほかは毎日入れ替え(同じ日は同じ順)
- **基礎ポイント** — `referral/data.js` の `REF_BASE_POINTS`。紹介診断では、話題かキーワードが合った人の点数にこの点を足します(合わない人を上げることはしません)
- **メンバーの詳細・資料** — カードの名前か「詳細・資料を見る」で、詳しいプロフィールと資料・リンク(提案資料・ホームページと、連絡先・SNS:LINE・Instagram・X・Facebook・TikTok・YouTube・Threads・LinkedIn・note・ブログ)を表示。資料・リンクは管理者ページと「自分の情報を編集」で1人12件まで登録でき(「+ LINE」「+ Instagram」などのボタンですぐ足せ、URL を貼ると種類が自動で選ばれる)、URL は `https://` から始まるもの(またはサイト内の `materials/` のファイル)だけを受け付けます
  - サイト内に置いた資料(`materials/`)は、URL を知っていればログインしなくても開けます。人に見せたくない資料は置かないでください
  - 資料の画像は縦横を切らずにそのまま表示します(16:9 の表紙も、A4横のシートも)。山本 捷真の資料のいちばん上には、パーソナルブランディングシート(`materials/yamamoto-branding.jpg`。押すと大きな画像が開く)を置いています
- **全体分析**(`/teams/`)— 系列に関係なく、コミュニティ全体の共通のお客様・今回る紹介(名簿から計算)と、迎えると仕事が回る具体的な業種(税理士・弁護士・不動産仲介・美容脱毛サロン・飲食店オーナーなど22業種と、紹介し合える人)を表示。業種の一覧は `teams/analysis.js`
- **自分の情報を編集**(`/profile/`)— 会員が自分で事業内容・主なお客様・求める紹介・こんな話が出たら・活動範囲・診断用のタグを入力できます(名前と所属チームは管理者のみ)。記入状況をパーセントで表示し、未入力の項目があると早見表の上部でお知らせします。各自の「自分のカード」にも編集ボタンがあります
- **名簿の管理**(`/admin/`・管理者のみ)— メンバーの追加・編集・削除、早見表の各項目と紹介診断のタグ(話題・業種・相手のタイプ)の入力、JSONの書き出し・読み込み。メンバーごとに「足りない情報」を表示し、「お願い文をコピー」でその人に足りない項目だけを聞くLINE用の文面を作れます。権限はサーバー層で確認します(一般会員は画面も API も `FORBIDDEN_ADMIN`)
- **作成者の表記** — 各ページのフッターに「Created by Shoma Yamamoto」と Lumenium のロゴを置き、どちらも https://lumenium.net へ新しいタブで開きます。サイトは参照元を送らない設定のため、どこから来たかは URL の `utm_source=bt-ex5`(`utm_campaign` は credit / footer_logo / opening_credit / opening_logo)で分かります
- **オープニングムービー**(`/opening/`)— ひとつの光が5つ(出会い・信頼・紹介・仕事・感謝)に分かれて金の糸で結ばれ、ご縁が巡り、糸がふくらんで金の輪(ロゴ)になり、閃光・光の筋・金の火の粉・うしろで回る後光とともに決まる13秒の映像(ロゴの太さや球はロゴの画像と同じ割合の立体。最後は BT-EX5 の文字にも光が流れる)(音あり。黒と金・細い線・広い字間の映画風の演出)。字幕は「出会いは、ひとつの光から。」「信頼で、つながる。」「ご縁が巡る、BT-EX5。」、最後に「新潟・東京　日本海側最大の経営者コミュニティ」。ログイン画面では開くたびに流れます(ブラウザの決まりで音なしで始まり、右上の「音を出す」で音が出る。画面のどこかを押すか、左上の「スキップ」で飛ばせる)。ログイン後は、ヘッダー右上の「▶ ムービー」でいつでも音ありで見られます。作り方は `opening/src/README.md`

## 名簿

- BT-EX5 の会員26名。山本 捷真と、プロフィールを受け取った24名は、事業内容・主なお客様・求める紹介を反映済み(元のページで未登録の項目は空欄)。佐藤 慎哉は会員名簿に表示されている名前のみです
- 活動範囲(対面のエリア・オンライン対応)が未入力のメンバーは「準備中」と表示されます
- 業種・診断用のタグ・トリガーワードはプロフィールからの仮設定なので、管理者ページで確認してください
- 電話番号・メールアドレス・住所・誕生日は、静的サイトでは誰でも取得できる状態になるため載せていません
- 初期名簿は `referral/data.js` の `REF_SEED_MEMBERS`。名簿が未作成のときに一度だけ投入され、以降の変更は管理者ページ・各会員の「自分の情報を編集」で行います
- 初期名簿を更新したときは `REF_SEED_REVISIONS` に対象メンバーを追加すると、既存の名簿にも一度だけ反映されます(管理者ページで編集済みのメンバーは空欄だけを埋めます)

## データの保存範囲(重要)

- **お試し版(今の状態)**: 名簿・自分の情報の編集・ログイン情報はブラウザ内(localStorage)に保存されます。**別の端末・別のブラウザとは共有されません**(画面にもその旨を表示しています)
- **共有サーバー**: `gas/` の Google Apps Script を運営者の Google スプレッドシートに設置し、`auth/api.js` の `API_BASE_URL` にその URL を設定すると、全員のデータが1つのスプレッドシートに集まります。手順は [gas/README.md](gas/README.md)
- 判定の本体 `auth/server-core.js`・`auth/server-community.js` はお試し版と共有サーバーで同じコードです。これらや `referral/data.js` を変えたら `node tools/build-gas.mjs` で `gas/Code.gs` を作り直してください
- パスコードはソースに平文では置かず、ソルト付き SHA-256 のハッシュだけを `auth/mock-server.js` の `PASSCODES` に持っています。ただし静的サイトのため、`referral/data.js` などのファイル自体はURLが分かれば誰でも取得できます。名簿の内容を確実に守るには、実バックエンドでの認証が必要です

### パスコードの変更

新しいパスコードのソルトとハッシュを作り、`auth/mock-server.js` の `PASSCODES` の該当行を差し替えます(照合時は小文字化し、ハイフンと空白を除きます)。

```bash
node -e 'const c=require("crypto");const n=process.argv[1].trim().toLowerCase().replace(/[\s-]/g,"");const salt=c.randomBytes(16).toString("hex");console.log("salt:",salt,"hash:",c.createHash("sha256").update(salt+":"+n).digest("hex"))' '新しいパスコード'
```
