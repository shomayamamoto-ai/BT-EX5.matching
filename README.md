# BT-EX5 紹介先早見表

新潟・東京の紹介者制(経営者)コミュニティ BT-EX5 の、会員同士のリファラル(紹介)を増やすための会員限定サイトです。サイトのトップ(`/`)を開くと紹介先早見表に移動し、未ログインの場合はログイン画面を経由します。会員登録はなく、コミュニティ共通のパスコードで入ります。

## 主な機能

- **紹介先早見表**(`/referral/`)— 会員ごとに「事業内容/求める紹介/こんな話が出たら(トリガーワード)/活動範囲(対面・オンライン)」を表形式で一覧化。キーワード検索・話題・業種・対応エリアで絞り込めます。「話題で探す」では、その話題を専門にしている人(扱う話題が少ない人)から順に並びます
- **紹介診断(マッチ率)** — 会話で出た話について5つの質問(話題・相手のタイプ・業種・エリア・会い方)に答えると、会員ごとの一致度(0〜100%)を計算し、上位5名を理由つきで表示。一覧を一致度順に並べ替えることもできます
  - 話題は6グループ・28項目(仕事・集客/お金・法律/人・組織・成長/住まい・地域/健康・暮らし/食・イベント)。ほかの人と重ならない具体的な話題(例:ケータリング・パーティー料理、会場・レンタルスペース、ネットショップ・EC)を持つ人が、その話題で確実に上位に来ます
  - 配点: 話題50(選んだ話題をどれだけ扱えるか42+本業に近いか8)+ 業種15 + 相手のタイプ10 + 会い方・エリア25(キーワード一致で+15)。話題もキーワードも一致しない人は30%で頭打ち。未入力の項目は中立の点数(活動範囲は25点中15点)
  - 同点のときは、キーワードが多く一致した人、扱う話題が少ない専門の人の順(名簿の並び順では決めない)
  - キーワードは、本人の説明文にその言葉があれば+15、話題の言いかえ(`TOPIC_KEYWORDS`。例:「婚活」→結婚・子育て)に当たれば+8(選んだ話題の言いかえは二重に数えない)
  - 計算は `referral/scoring.js`(画面に依存しないので、回答の全組み合わせでの出やすさを確かめられます)
- **紹介文をコピー** — 診断した話題を織り込んだ紹介文を自動作成してコピー。本人が「自己紹介文」を登録していれば、それを原文のまま入れます(自己紹介文はキーワード検索の対象にもなります)
- **あなたと紹介し合えそうな人** — 同じお客様を持ち、別のサービスを出している人を早見表の上部(と各メンバーの詳細画面)に3名まで表示。「求める紹介」とお客様・事業の言葉の重なり、「求める紹介」に当てはまる話題、紹介してほしい業種の重なりで計算し、扱う話題がほとんど同じ人(競合しやすい人)は下げます(`referral/partners.js`)
- **紹介特典** — 「BT-EX5のメンバーから紹介されたお客様への特典」(例:初回相談無料)を各自が登録でき、カード・詳細・紹介文に入ります。「紹介特典あり」で絞り込めます(登録している人がいるときだけ表示)
- **並び順** — 検索・診断の前の一覧は、1番目が利用者本人、2番目がサイトの作成者(山本 捷真)、ほかは毎日入れ替え(同じ日は同じ順)
- **メンバーの詳細・資料** — カードの名前か「詳細・資料を見る」で、詳しいプロフィールと資料・リンク(提案資料・ホームページ・Instagram・LINE など)を表示。資料・リンクは管理者ページと「自分の情報を編集」で登録でき、URL は `https://` から始まるもの(またはサイト内の `materials/` のファイル)だけを受け付けます
  - サイト内に置いた資料(`materials/`)は、URL を知っていればログインしなくても開けます。人に見せたくない資料は置かないでください
- **全体分析**(`/teams/`)— 系列に関係なく、コミュニティ全体の共通のお客様・今回る紹介(名簿から計算)と、迎えると仕事が回る具体的な業種(税理士・弁護士・不動産仲介・美容脱毛サロン・飲食店オーナーなど22業種と、紹介し合える人)を表示。業種の一覧は `teams/analysis.js`
- 紹介数の記録・集計・ランキング・紹介の受け渡しは、別の会員システムと二重になるため、この早見表には置いていません(サーバー側の機能 `recordReferral` などは残してあり、必要になれば画面を戻せます)
- **自分の情報を編集**(`/profile/`)— 会員が自分で事業内容・主なお客様・求める紹介・こんな話が出たら・活動範囲・診断用のタグを入力できます(名前と所属チームは管理者のみ)。記入状況をパーセントで表示し、未入力の項目があると早見表の上部でお知らせします。各自の「自分のカード」にも編集ボタンがあります
- **名簿の管理**(`/admin/`・管理者のみ)— メンバーの追加・編集・削除、早見表の各項目と紹介診断のタグ(話題・業種・相手のタイプ)の入力、JSONの書き出し・読み込み。メンバーごとに「足りない情報」を表示し、「お願い文をコピー」でその人に足りない項目だけを聞くLINE用の文面を作れます。権限はサーバー層で確認します(一般会員は画面も API も `FORBIDDEN_ADMIN`)
- **オープニングムービー**(`/opening/`)— ひとつの光が5つに分かれて糸で結ばれ、紹介が巡ってロゴになる12秒の映像(音あり)。ログイン画面では、その端末で初めて開いたときに1回だけ流れます(音なしで開始・スキップ可・動きを減らす設定の人には流さない)。作り方は `opening/src/README.md`
- **パスコードでログイン**(`/login/`)— パスコードを入力し、名簿から自分の名前を選んで入ります。選んだ名前の「自分の情報」を編集できます
  - パスコードは2種類: **会員用**(閲覧・自分の情報の編集)と **管理者用**(会員用の権限+名簿の管理)。パスコードは運営者から会員に伝えてください
  - 5回続けて間違えると15分ロック。ログイン状態の保持はオフ12時間/オン30日。マイページ(`/portal/`)からログアウトできます
  - 設計は `docs/specs/login-page-detailed-spec-v3.md` を下敷きにしています(パスコード方式への読み替えは `docs/specs/README.md`)

## 名簿

- BT-EX5 の会員26名。山本 捷真と、プロフィールを受け取った24名は、事業内容・主なお客様・求める紹介を反映済み(元のページで未登録の項目は空欄)。佐藤 慎哉は会員名簿に表示されている名前のみです
- 活動範囲(対面のエリア・オンライン対応)が未入力のメンバーは「準備中」と表示されます
- 業種・診断用のタグ・トリガーワードはプロフィールからの仮設定なので、管理者ページで確認してください
- 電話番号・メールアドレス・住所・誕生日は、静的サイトでは誰でも取得できる状態になるため載せていません
- 初期名簿は `referral/data.js` の `REF_SEED_MEMBERS`。名簿が未作成のときに一度だけ投入され、以降の変更は管理者ページ・各会員の「自分の情報を編集」で行います
- 初期名簿を更新したときは `REF_SEED_REVISIONS` に対象メンバーを追加すると、既存の名簿にも一度だけ反映されます(管理者ページで編集済みのメンバーは空欄だけを埋めます)

## データの保存範囲(重要)

- **お試し版(今の状態)**: 名簿・自分の情報の編集・ログイン情報はブラウザ内(localStorage)に保存されます。**別の端末・別のブラウザとは共有されません**(画面にもその旨を表示しています)
- **共有サーバー**: `gas/` の Google Apps Script を運営者の Google スプレッドシートに設置し、`auth/api.js` の `API_BASE_URL` にその URL を設定すると、全員のデータが1つのスプレッドシートに集まります。手順は [gas/README.md](gas/README.md)
- 判定の本体 `auth/server-core.js` はお試し版と共有サーバーで同じコードです。`auth/server-core.js` や `referral/data.js` を変えたら `node tools/build-gas.mjs` で `gas/Code.gs` を作り直してください
- パスコードはソースに平文では置かず、ソルト付き SHA-256 のハッシュだけを `auth/mock-server.js` の `PASSCODES` に持っています。ただし静的サイトのため、`referral/data.js` などのファイル自体はURLが分かれば誰でも取得できます。名簿の内容を確実に守るには、実バックエンドでの認証が必要です

### パスコードの変更

新しいパスコードのソルトとハッシュを作り、`auth/mock-server.js` の `PASSCODES` の該当行を差し替えます(照合時は小文字化し、ハイフンと空白を除きます)。

```bash
node -e 'const c=require("crypto");const n=process.argv[1].trim().toLowerCase().replace(/[\s-]/g,"");const salt=c.randomBytes(16).toString("hex");console.log("salt:",salt,"hash:",c.createHash("sha256").update(salt+":"+n).digest("hex"))' '新しいパスコード'
```

## 更新するとき

ページが読み込む `.js` / `.css` には `?v=<日時>` を付けています(ブラウザが古いファイルを使い続けないようにするため)。ファイルを変えたら次を実行してから公開してください。

```bash
node tools/stamp-assets.mjs   # 各ページの ?v= を付け直す
node tools/build-gas.mjs      # 共有サーバー用の gas/Code.gs を作り直す
```

## 技術構成

ビルド不要の静的サイトです(HTML / CSS / Vanilla JavaScript)。

```
index.html            … 紹介先早見表へ移動する入口
referral/             … 紹介先早見表・紹介診断(data.js に初期名簿と診断の選択肢)
admin/                … 名簿の管理(管理者のみ)
profile/              … 自分の情報を編集(会員本人)
login/  portal/  terms/ … ログイン(パスコード)・マイページ・利用規約
auth/                 … 認証共通層(api / session / ui / 各画面ロジック)
  server-core.js      … サーバー側の判定(お試し版と共有サーバーで共通)
  mock-server.js      … お試し版の保存先(localStorage)
gas/                  … 共有サーバー(Google Apps Script)。Code.gs は自動生成
tools/build-gas.mjs   … gas/Code.gs を作るスクリプト
assets/bt-ex5-mark.svg … BT-EX5 のロゴマーク(5つの点を1本の糸で結んだ五角形。オープニングの結び目と同じ形)
assets/opening/       … オープニングムービー(MP4 1080p/720p、WebM 720p、ポスター画像)
opening/              … オープニングの映像(opening.js)・ログイン画面での再生(intro.js)・作り方(src/)
docs/specs/           … 仕様書(実装の正)
```

## 動かし方

任意の静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
