# BT-EX5 紹介先早見表

新潟・東京の紹介者制(経営者)コミュニティ BT-EX5 の、会員同士のリファラル(紹介)を増やすための会員限定サイトです。サイトのトップ(`/`)を開くと紹介先早見表に移動し、未ログインの場合はログイン画面を経由します。

## 主な機能

- **紹介先早見表**(`/referral/`)— 会員ごとに「事業内容/求める紹介/こんな話が出たら(トリガーワード)/活動範囲(対面・オンライン)」を表形式で一覧化。キーワード検索・業種・対応エリアで絞り込めます
- **紹介診断(マッチ率)** — 会話で出た話について5つの質問(話題・相手のタイプ・業種・エリア・会い方)に答えると、会員ごとの一致度(0〜100%)を計算し、上位5名を理由つきで表示。一覧を一致度順に並べ替えることもできます
  - 配点: 話題50 + 業種15 + 相手のタイプ10 + 会い方・エリア25(キーワード一致で+10)。話題もキーワードも一致しない人は30%で頭打ち。未入力の項目は中立の点数
- **紹介文をコピー/LINEで送る** — 診断した話題を織り込んだ紹介文を自動作成し、コピーまたはLINEで共有
- **紹介の記録と実績** — 「紹介を記録」で紹介した事実(紹介した相手は任意)を記録。あなたの紹介数・今月のコミュニティ全体の紹介数・これまでの合計・紹介貢献ランキング(上位5名)を表示し、各会員のカードには受けた紹介の件数を表示します。自分の記録は取り消せます
- **名簿の管理**(`/admin/`・管理者のみ)— メンバーの追加・編集・削除、早見表の各項目と紹介診断のタグ(話題・業種・相手のタイプ)の入力、JSONの書き出し・読み込み。権限はサーバー層で確認します(一般会員は画面も API も `FORBIDDEN_ADMIN`)
- **ログイン・会員登録・マイページ・パスワード再設定** — `docs/specs/login-page-detailed-spec-v3.md` を設計仕様として実装(適用方針は `docs/specs/README.md`)

## 名簿

- BT-EX5 の会員27名。山本 捷真以外は会員名簿に表示されている肩書き・所属チームのみ反映しており、求める紹介・活動範囲などは「準備中」です
- 業種と診断用の話題タグは肩書きからの仮設定なので、管理者ページで確認してください
- 初期名簿は `referral/data.js` の `REF_SEED_MEMBERS`。名簿が未作成のときに一度だけ投入され、以降の変更は管理者ページで行います

## データの保存範囲(重要)

- 現在はバックエンドがないため、名簿・紹介の記録・アカウントはブラウザ内(localStorage)のデモ用サーバー層 `auth/mock-server.js` に保存されます。**別の端末・別のブラウザとは共有されません**
- 実バックエンド(GAS / Firebase 等)へ接続する場合は、`auth/api.js` の `API_BASE_URL` を設定すると、同じ契約の API を text/plain POST で呼びます
- デモの管理者アカウントは `demo@kouryukai.jp` / `kouryukai-demo-2026` です。本番では管理者権限をサーバー側で正しく付与してください

## 技術構成

ビルド不要の静的サイトです(HTML / CSS / Vanilla JavaScript)。

```
index.html            … 紹介先早見表へ移動する入口
referral/             … 紹介先早見表・紹介診断・紹介の記録(data.js に初期名簿と診断の選択肢)
admin/                … 名簿の管理(管理者のみ)
login/  register/  portal/  password/reset/  terms/  privacy/ … 認証・会員関連ページ
auth/                 … 認証共通層(api / session / ui / mock-server / 各画面ロジック)
assets/bt-ex5-mark.svg … BT-EX5 のロゴマーク
docs/specs/           … 仕様書(実装の正)
```

## 動かし方

任意の静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
