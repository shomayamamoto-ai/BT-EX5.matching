# 共有サーバーの設定(Google Apps Script)

今のサイトは「お試し版」で、名簿・紹介の記録・定例会・掲示板・メッセージなどは **それぞれの端末のブラウザの中だけ** に保存されます。メンバー全員で同じデータを使うには、Google スプレッドシートを使った共有サーバーを用意します(無料・Google アカウントがあれば作れます)。

## 用意するもの

- 運営者の Google アカウント
- このフォルダの `Code.gs`(サイトのデータ定義とサーバーの処理をひとつにまとめたファイル)

## 手順(10分ほど)

1. **スプレッドシートを作る**
   Google ドライブで「新規 → Google スプレッドシート」を作り、名前を「BT-EX5 紹介先早見表」などにします。
2. **Apps Script を開く**
   スプレッドシートのメニュー「拡張機能 → Apps Script」を開きます。
3. **コードを貼り付ける**
   最初からある `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の中身をすべて貼り付けて保存(💾)します。
4. **初回の準備を実行する**
   上部の関数の選択欄で `setup` を選び「実行」を押します。権限の確認が出たら、運営者のアカウントで「許可」します(「このアプリは確認されていません」と出た場合は「詳細 → 安全ではないページに移動」)。
   実行後、スプレッドシートに「名簿」「紹介の記録」などのシートができます。
5. **Web アプリとして公開する**
   右上の「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」を選び、
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   にして「デプロイ」します。表示された **ウェブアプリの URL**(`https://script.google.com/macros/s/…/exec`)をコピーします。
6. **サイトに URL を設定する**
   `auth/api.js` の `const API_BASE_URL = "";` の `""` の中に、コピーした URL を入れて保存し、GitHub に反映します(URL を開発担当に渡してもらえれば設定します)。

7. **(1on1 を Google カレンダー・Google Meet と連携するとき)**
   Apps Script の左の「サービス」の「＋」→「Google Calendar API」を選んで「追加」します。もう一度 `setup` を実行すると、カレンダーの権限の確認が出るので「許可」します。運営者のアカウントに専用のカレンダー「BT-EX5 1on1」ができます。最後に「デプロイ → デプロイを管理 → 編集 → 新バージョン」で更新します。
   - 1on1 を「予定」で保存すると、このカレンダーに予定ができ、2人がマイページで登録したメールアドレスに招待が届きます(Gmail なら各自の Google カレンダーに自動で入る)。
   - 場所で「Google Meet」を選ぶと、Meet の会議も自動で作られ、アプリに「Meet に参加」が出ます。
   - 日時を変えると予定も変わり、「中止」や削除で予定も消えます。
   - 追加しなくてもサイトは動きます(その場合は、各自が「カレンダーに追加」と「Meet を作る」で手動で作ります)。

これで、全員のデータが同じスプレッドシートに集まります。続けて、README の「本番に切り替える手順」で会員に招待コードを送ってください。

## 知っておいてほしいこと

- **パスコードは今のものがそのまま使えます。** サーバー側でもハッシュ(元に戻せない形)だけを持っています。会員のパスワード・招待コードもハッシュだけを保存します。
- **「名簿」「紹介の記録」「ありがとうマイル」「定例会の出欠」「ビジター」「1on1」シートは確認用です。** 集計や名簿の配布にそのまま使えます(Excel への書き出しも可)。 サイトで変更があるたびに自動で書き直されるため、シートを直接編集しても反映されません。編集はサイト(名簿の管理・自分の情報を編集)から行ってください。
- スプレッドシートの共有範囲は運営者だけにしてください(紹介した相手の連絡先・ビジターの連絡先が入ります)。
- メッセージ・掲示板・運営連絡は「_data」シートにだけ入ります(1つのやりとりは最新500件、掲示板は最新400件まで保存)。
- メッセージは、やりとりの画面を開いている間だけ8秒ごとに新着を確認します(画面が隠れている間は止まる)。ほかの画面は開いたときだけ読み込むので、サーバーへの負荷は小さくしています。
- 実際のデータは非表示の「_data」シートに入っています。消したり書き換えたりしないでください。バックアップはスプレッドシートの「ファイル → コピーを作成」で取れます。
- お試し版で入力した名簿は、管理者ページの「JSONを書き出す」で保存し、共有サーバーに切り替えたあと「JSONを読み込む」で移せます。

## サイトのデータ定義を変えたとき

`referral/data.js`(話題・業種の選択肢や初期名簿)や `auth/server-core.js`・`auth/server-community.js` を変えたら、次のコマンドで `Code.gs` を作り直し、Apps Script に貼り付け直して「デプロイ → デプロイを管理 → 編集 → 新バージョン」で更新します。

```bash
node tools/build-gas.mjs
```

`Code.gs` は `referral/data.js`・`auth/server-core.js`・`auth/server-community.js`・`gas/main.js` をつないだものなので、直接は編集しません。
