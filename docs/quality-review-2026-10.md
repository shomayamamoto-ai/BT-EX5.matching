# BT-EX5 会員アプリ 有料化に向けた品質の見直し(2026年10月)

BT-EX5 の会員向けに有料で提供できる品質にするため、4つの方向から調べ、直せるものから直しました。

1. 紹介団体のアプリ(BNI Connect・BNI+・BNI Timer・ClubRunner・Referral Grove など)との比較
2. 会員・コミュニティ向けの有料サービス(Circle・Mighty Networks・Skool・Hivebrite・Glue Up・Peatix・LINE WORKS・osiro など)の作り
3. 全画面の見た目と使いやすさの点検(スマホ 390px・パソコン 1440px)
4. 不具合・セキュリティ・個人情報・速さの点検(コード)

---

## 1. いちばん大事なこと: いまサイトは「お試し版」のまま動いています

`auth/api.js` の `API_BASE_URL` が空のため、サイトは各端末のブラウザの中だけで動いています(共有サーバーにつながっていません)。

- 紹介・掲示板・運営連絡・出欠などは、**その端末の中にしか保存されず、ほかの会員には届きません**。
- 画面に出ている「いまはお試し版のため…」の文言も、このためです(共有サーバーにつなぐと自動で消えます)。
- 運営連絡の書き足しが「反映されない」と感じた原因も、ここにあります。

**有料で提供する前に、まず共有サーバー(Google Apps Script)の URL を設定する必要があります。**
手順: `gas/README.md` の手順でデプロイ → 「ウェブアプリの URL(…/exec)」を `auth/api.js` の `API_BASE_URL` に入れる(URL を教えていただければ、こちらで設定します)。

あわせて、有料で使う前に **パスコードを長いものに変えてください**(`gas/README.md` の「パスコードを新しくする」)。

## 2. 競合と比べてわかったこと

### 紹介団体アプリ(BNI など)
- 会費を払う理由の中心は「紹介・成約のお礼(TYFCB)・1to1・出席」の記録と、その見える化(信号=トラフィックライト)。
- 高く評価されている点: 数タップで記録できる、数字が正確、定例会の進行(アジェンダ・タイマー・プレゼンの順番)が1か所にまとまっている。
- BNI アプリへの不満: ログインできない・落ちる、全項目必須の入力、検索が厳しすぎる、メニューが深い、金額の打ちまちがい、締め時刻をすぎた入力が翌週扱い、ツールがバラバラ。
- 日本の経営者団体(守成クラブ・倫理法人会など)には、成熟した会員アプリがほとんどない(LINE と紙が中心)。**差をつけやすい分野**です。

### 会員コミュニティの有料サービス
- 入会直後に迷わせない(ウェルカムのチェックリスト)、所属の証(会員証)、運営が既読を確かめて未読の人へもう一度知らせる、が「払う価値」として効いている。
- 日本では通知の本線は LINE(LINE Notify は 2025年3月で終了。いまは LINE 公式アカウント+Messaging API)。iPhone の Web プッシュはホーム画面に追加したときだけ届く。
- 少人数では、公開ランキングより「自分だけの信号」「みんなで目指す目標」「称賛」のほうが続きやすい。

## 3. 今回入れた・直したもの

### 新しい機能
| 機能 | 参考にしたもの |
|---|---|
| **BT-EX5 シグナル**(直近6か月の活動を100点で。本人だけに表示、次にやるとよいこと付き) | BNI の信号(トラフィックライト) |
| **デジタル会員証**(黒と金のカード・QR) | osiro・Wild Apricot の会員証 |
| **はじめての方へ**(7つのステップのチェックリスト) | Mighty Networks のウェルカムチェックリスト |
| **使い方・よくある質問**(見える範囲・困ったとき・問い合わせ) | 各社のヘルプセンター |
| **未読の人にもう一度通知**(運営連絡) | LINE WORKS の未読者への再通知 |
| これまでに入れたもの: 30秒プレゼンの進行(順番タイマー)、1on1 のおすすめ、ホームの表示の選択 | BNI+・BNI Timer・Heartbeat |

### 安心して使うための修正(セキュリティ・信頼性)
- 共通パスコードで、パスワードを決めた会員や管理者になりすませた問題を修正
- 共通パスコードで入ったセッションは管理者にならないように
- ログイン失敗の回数を人ごとに(だれかの失敗で全員がロックされない)
- セッションをハッシュで保存、パスコードのハッシュをサーバーだけに置けるように
- 電波が弱いだけでログアウトされないように、通信は30秒で打ち切り
- 2重投稿・2重通知の防止、お礼の金額と件数の上限、CSV の数式対策、時刻の検証
- 1on1 のカレンダー招待で相手のメールアドレスを見せない
- 共有サーバーを速く(中身が変わらないときは保存しない、一覧シートの作り直しを1分に1回まで)

### 見た目・使いやすさ
- 入力のまちがいを、その欄のすぐ下に出して欄まで動かす
- ランキングの同点を「同率◯位」に、0pt では順位を出さない
- 文字は最小12px、補足の文字とフォーカスの枠を濃く、1〜2文字だけの改行を防ぐ
- 名前の丸・状態の印・切り替えの色を黒と金に統一
- マイページを4つのまとまりに、パソコンは2列
- 読み込み中はカード形のひな形、お知らせは成功・失敗で印を分ける
- 掲示板の長い投稿は折りたたみ、空の画面には次の一手のボタン
- 申込締切は「10/14(水) 23:59まで」の書き方に
- ビジター申込ページを仕上げ、個人情報の取り扱いを明記

## 3-5. 第5弾(2026年10月12日): 3つの方向からの点検と修正

会員アプリ・単体のツール(早見表・プロフィールなど)・運営の画面と全体の一貫性の3つに分けて、スマホとパソコンで1画面ずつ操作して点検し、見つかったものを直しました。

| 分野 | 直したもの |
|---|---|
| 共有サーバー | 見るだけの操作(ホーム・一覧など)は書きこみの順番待ちをせずに読む。書きこみが要るとき・書きかけを読んだときはロックを取ってやり直す(データを壊さない) |
| 全体 | 削除などのボタンをどの画面でも赤に。ブラウザの灰色の確認ダイアログを、アプリの確認シート(戻せない操作は赤いボタン)に。小さいボタン・ベル・名前の丸も押せる範囲を 44px に。薄くて読みにくかった文字を濃く。入力のまちがいを「✓」のお知らせで出していたのを、欄の下の赤い表示に。お知らせの帯が途中で折り返さないように。ヘッダーのロゴを軽く(56KB → 8KB) |
| 早見表・プロフィール・全体分析 | 上の帯にアプリと同じベル(未読の数)と名前の丸、ロゴはどこからでもアプリのホームへ。パソコンの一覧の列がずれるのを修正。ほかの人のカードに「未入力」「まだ入力されていません」を出さない。「解除」が2行になるのを修正、並びの説明を「〇〇に強い順」に。紹介診断の選択肢の幅をそろえ、下のボタンの帯を透けないように |
| プロフィール | 「こんな話が出たら」が12個をこえると、保存のたびに黙って消えていたのを修正(24個まで。こえているときは保存の前に知らせる)。保存できない理由を保存ボタンのそばに出し、直す欄まで動かす |
| 記録 | ありがとうを送ったあとに空のフォームがまた開くのを修正。金額に数字以外を入れたときは知らせる。ランキングの空のグラフを1行の案内に。紹介の一覧は中身のあるほうを先に、長いメモは4行でたたむ |
| 掲示板 | コメントの削除を確認つきに、直すときはブラウザの入力ダイアログではなくシートで。時刻・編集・削除の並びを整える |
| 探す(アプリ内検索) | 言葉の印が2文字ずれていたのを修正 |
| お知らせ・ありがとう | 運営連絡は見出しを本文の題名に。受け取ったありがとうの言葉を3行まで読めるように |
| 予定 | スマホでは時計を小さくし、カレンダーと出欠のボタンが早く見えるように。パソコンのカレンダーの予定名を「定例会」に。詳細の時刻・締切が途中で折り返さないように |
| 運営(管理者) | スマホで「LINE 連携」「バグ・要望」のタブが隠れていたのを2段に。会費・LINE の集計を数字のカードに、会費の一覧は名簿の順・スマホは名前の下に操作。会員アカウントで自分の行を「ログイン中」に(自分を管理者から外すボタンは出さない)。ダッシュボードの長い表は5行+「すべて見る」、開催前の定例会は「開催前」。出欠は開催前はたたみ、「出席予定の人をまとめて出席」。名簿の管理は「入力待ち/あと少し/記入済み」の3段階、JSON の読み書きは「開発者向け」にしまう、保存できない理由を下のボタンのそばに。LINE 未設定のときの技術的な手順は「開発者向け」にしまう |
| ことば | 「リファーラル」→「紹介」、出欠は「出席予定・欠席・未回答」、「(管理者)」「タップで開く」を外す、ビジター申込ページの参加費が「会員 無料」と出ていたのを「招待したメンバーにご確認ください」に |

## 4. 残っている課題(次にやるとよいこと)

### 運営の判断が必要なもの
1. **共有サーバーへの切り替え**(上の1)— 最優先
2. **フッターの制作者表記と、早見表の「本システム開発者」表示**: 有料の会員アプリとしては、中立に見えるよう利用規約ページへ移すことをおすすめします(以前のご依頼で入れたものなので、残すかどうかご判断ください)。
3. **LINE 公式アカウントでの通知**: 経営者に確実に届くのは LINE。公式アカウントを作れば、運営連絡・紹介の通知を LINE でも送れるようにできます。
4. **会費の決済・領収書**(インボイス対応): 有料化の形(月額・年額、決済方法)が決まれば組み込めます。

### 作りの改善(時間をかけて進めるもの)
- ページごとに違う見出し(ヘッダー)と「探す」の呼び方の統一
- ボタンの種類と角の丸みの統一(主・副・控えめ・削除の4種類)
- 絵文字のアイコンを、線のアイコンに置きかえる
- パソコンでのメニューの位置(本文に重ならない形)
- 公開ページ(ビジター申込・ログイン)から、名簿の初期データを読み込まないようにする(共有サーバーに切り替えたあと)
- 共有サーバーの読み込みの高速化(読み込みだけの操作をロックなしに)
